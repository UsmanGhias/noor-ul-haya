# Contributing to Noor ul Haya

JazakAllah khair for helping build Noor ul Haya into a trusted Quran Majeed and Islamic companion for the Ummah.

## Public repository

The project is open source at https://github.com/UsmanGhias/noor. You can star the repository, open issues, discuss improvements, and send pull requests.

## How to contribute

1. Fork the repository.
2. Create a focused branch for one feature, fix, or documentation update.
3. Run the relevant Flutter checks before opening a pull request.
4. Explain what changed, why it helps users, and how you tested it.

## Contribution ideas

- Quran Majeed reading experience improvements.
- Prayer time accuracy and alarm reliability fixes.
- Qibla, Duas, Tasbih, and settings enhancements.
- Accessibility, localization, and offline experience improvements.
- Tests, documentation, release automation, and performance work.
